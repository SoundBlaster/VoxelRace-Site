VOXEL RACE / SUPPORT

How can we help?

Questions about racing, creating a track, sharing a file or using Game Center? Email the developer:

egor.merkushev@yandex.ru

Include your device model, iOS or iPadOS version, and a short description of what happened. Please avoid sending sensitive information.

Quick answers

  • Creating a track: open Tracks, choose Create Track and a map size, then drag the points or the road to reshape it.
  • Sharing a track: use the share action in the track catalog. The file includes this device’s local best scores for that track when available, including player names.
  • Game Center: sign in to Game Center and enable score sharing in the game if you want to submit classic-track results. Custom tracks use local scores.
  • Appearance: the game follows your device’s Light or Dark Mode.

The game interface is in English.

VOXEL RACE / ПОДДЕРЖКА

Чем помочь?

Есть вопросы о гонке, редакторе трасс, обмене файлами или Game Center? Напишите разработчику:

egor.merkushev@yandex.ru

Укажите модель устройства, версию iOS или iPadOS и кратко опишите проблему. Пожалуйста, не отправляйте чувствительные данные.

Короткие ответы

  • Создание трассы: откройте Tracks, выберите Create Track и размер карты, затем меняйте форму, перетаскивая точки или дорогу.
  • Обмен трассой: используйте действие отправки в каталоге трасс. Если на устройстве есть локальные рекорды для этой трассы, файл содержит их вместе с именами игроков.
  • Game Center: войдите в Game Center и включите отправку очков в игре, если хотите отправлять результаты классической трассы. Для пользовательских трасс используются локальные результаты.
  • Оформление: игра следует светлой или тёмной теме устройства.

Интерфейс игры — на английском языке.
